# Distinct capability

This benchmark isolates a shared preload handoff across twelve independent spring contacts. One arm compresses the plate while the other inserts a separate retaining key. All contacts must remain seated after release. The declared setup starts with loaded cells, concentrating the benchmark on load transfer and closure.

RoboCurve PR #1303 places a holder over four upright cells. The distinction here is the mechanically retained spring load, established through loaded/keyed and released/unkeyed native probes. RoboCurve PR #688 exchanges grouped UPS modules. This task measures the contact-pressure closure.

The broader comparison against LIBERO, RoboCasa, SimplerEnv, BEHAVIOR, DataCenterBench and RoboDojo is preserved in the coordination literature screen. Contact preload and independent key retention form the contribution. Object count supplies contact-distribution complexity. Current official PRs must be refreshed before submission. Internal review does not establish official acceptance.

The earlier full cell-loading implementation remains preserved in Git history. This focused revision requires its own genuine expert and model evidence.

The closer spring-load comparison is [spring-loaded flange isolation, PR #1403](https://github.com/robocurve/benchmark-tasks/pull/1403), board task TK-BULS8D. Both require one hand to sustain spring displacement while the other introduces a part. Its implementation has one 100 N/m prismatic flange; release clamps the inserted blind plate directly by spring pressure and friction. Here twelve independent terminal shoes push on a separate free pressure plate, and a distinct cross-key bears that plate through fixed channels after both arms release. The objective requires every contact's compression and seating, together with the plate and key poses. The contribution is distributed preload capture through a separate mechanical retaining element, rather than a larger cell count or a renamed flange clamp. Shared hold/insert/release structure remains an importance-review risk; this is an engineering distinction, not an acceptance guarantee.

TK-T3XFRM (chip carrier under a spring clip) similarly opens a spring jaw and clamps the workpiece on release; it does not transfer a distributed terminal load from a free plate into a separate retaining key. TK-ZEREPP adjusts carriage compliance and verifies side-load/drag tradeoffs, rather than assembling a preload closure. These comparisons use the official board specifications; the flange comparison additionally inspected its task construction, declared spring parameters and scoring code. Public demo and test sources were archived for reference, without counting an archive as an executed validation. No code or assets from those submissions are incorporated.
