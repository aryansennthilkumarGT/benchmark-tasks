# Scripted demonstration

The expert executes the fixed 14-dimensional robot joint/jaw commands in `expert_joint_trajectory.json`. These commands were authored offline from physical development trajectories. During execution the expert does not read object poses, mechanism joints, scoring predicates or hidden simulator state. It stops after a fixed action count; stopping does not imply success. The official scorer independently evaluates actual physical observations. Authored checkpoints identify command indices, not measured phase completion. `controller.json` and feedback utilities are retained for offline development and mechanism tests; they are not called by the demonstration expert.
