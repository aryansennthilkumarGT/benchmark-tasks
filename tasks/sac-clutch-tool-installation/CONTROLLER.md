# Executable SAC expert

`controller.json` is generated from the fixture. It contains the complete 597-phase plan: carrier tab approach/acquisition, lift clear of stud/mandrel tips, transfer and slow three-slot insertion, release and left-arm park; initialize the right arm; acquire/transfer/enter each of the three retainers; four turns per retainer as 32 clockwise 45° strokes with matching 0.375 mm descent; open, lift 20 mm, unwind, return and regrasp between strokes; release each flush retainer; final park and 2.5 s released hold.

`expert.py` binds the official 14-dimensional absolute joint/gripper action interface to `feedback.Controller`. Only joint observations and observation time are read. Authored waypoint geometry is known from setup; object telemetry, collision state, score, attachments and simulator state writes are absent from policy code. `nominal_bodies` accompanies the plan only for offline audits and is not used by feedback.

Motion uses one interpolation fraction for translation and rotation to preserve the screw lead between endpoints, limits joint-reference changes, and it waits for measured joints to catch up. Every phase checks actual TCP position/orientation through official FK and measured jaw aperture in the expected solid-part width band. The acquisition band does not prove frictional grasp integrity: slipped parts may leave no conclusive proprioceptive signature, which is a native risk. Recovery never declares success.

A no-progress period of 8 s or phase timeout initiates bounded recovery only where a mechanical action is known: reopen/reacquire for grip phases, or reverse exactly the current 45°/0.375 mm thread increment before retry. Each phase permits at most two attempts, each recovery at most 12 s. Other stalls stop; IK failures, invalid/stale observations and action-limit exhaustion fail immediately. A thread retry preserves the remaining engaged thread and does not pull the nut axially off the stud. There is no dynamic part teleport, snap, virtual wrench or force-law substitution.

`audit_sequence.py` executes the actual FK/IK feedback code against ideal joint tracking and explicitly injected jaw-contact apertures. Its completion tests controller sequencing, not native control success. Native prefixes first verify carrier placement, then one complete retainer; two full expert trials must subsequently pass independently before Dream is allowed. Fine thread contact, support stability and slip remain unqualified until those trials run.

`test_coupled_motion.py` uses actual official FK/IK to check the entire 45° tightening stroke against the 3 mm/turn lead, with an 80 µm maximum path-error bound. The earlier independent rate saturations failed this test and were repaired; endpoint IK alone had not exposed that defect. Native contact qualification remains mandatory.

Efficiency variant: the unchanged 45°/0.375 mm contact strokes remain slow and synchronized. Open-jaw regrasp clearance is 20 mm instead of 45 mm; unloaded return speed is 25 mm/s instead of 6 mm/s. Actual controller ideal tracking falls from 28,800 to 15,315 actions (765.75 s), a 46.8% reduction. Thread turns, targets, scorer and mechanical task are unchanged. The action limit is 24,000 instead of 42,000. Full FK path sampling adds 1,345 checks with ideal held-part transforms at 1 Hz plus phase boundaries; no native speed/grasp success is claimed.
