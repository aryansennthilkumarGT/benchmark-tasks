# Adversarial construct-validity review

The occupational source is automotive SAC tool preparation, not a generic spring plate. Essential preserved demands are simultaneous alignment of a three-slot carrier with three fixed axes and an occupied central bore, physical carrier seating, independent starting/turning/regrasping of three retainers, bearing retention and unsupported final stability. The manufacturer step is recognizably the unloaded precursor to spindle compression. No manufacturer force/dimension is claimed where absent.

| Shortcut or weakness | Mechanism/check | Remaining limitation |
|---|---|---|
| Put a solid plate over invisible pins | Real open slots, bore, mandrel, shoulders and studs; no contact exclusions | Native solver contacts not yet qualified |
| Pass through the centering tool | Real bore/mandrel collision geometry and numerical penetration guard | Contact offsets/CCD need native tests |
| Drop nuts to flush pose | Male/female thread interference; continuous engagement history and absolute phase check | Deliberately initialized probes are not policy demonstrations |
| Spin in air then drop | Histories reset on nonhelical travel, lateral loss or site change | Temporal evidence is required, not only a still photo |
| Tighten three nuts on one stud | Unique physical body histories and distinct-site matching | Duplicate-body telemetry invalidates trial |
| Hold carrier/nuts in a gripper | Real robot release clearance and two-second stability | Clearance uses conservative link boxes in native telemetry |
| Move/break fixture or lose a part | Anchors, normalization, loss-plane and penetration invalidation latch zero | Rigid parts do not model fracture; catastrophic invalid states are rejected |
| Infer production upper threads from M8 flywheel stud | Separate 12 mm/3 mm benchmark definition and provenance validator | No production interchangeability claim |
| Claim full clutch repair from unloaded setup | Explicit operation boundary and fidelity disclosure | No diaphragm, adjustment-ring or torque skill tested |
| Perfect circular nut hides rotation | Knurled profile and painted witness line; height/phase history | Video must show the mark sufficiently to count motion |
| Controller secretly knows object state | AST/loader tests; feedback consumes only robot joints/time | Known deterministic setup, no random visual localization challenge |

**Review outcome:** defensible as a narrow tool-mounting skill with deliberately authored dimensions, conditional on native feasibility. It is not a proxy for the complete occupational SAC installation. Missing production dimensions no longer prevent representing this selected skill because the fixture preserves the required insertion/retention topology and actual contact threads. The coarse custom thread makes acquisition easier; performance must not be interpreted as production fine-thread proficiency. The narrow scope and incomplete board inventory are acceptance risks, not facts to conceal. If native contacts or expert grasping fail, repair and revalidate; if reviewers require full spring/preload skill, this package cannot honestly satisfy that demand by renaming metadata.

Tests exercise reset, false final poses, free spinning, nonhelical drop, wrong thread phase, non-C3 placement, site swapping, repeated-site use, backing out, fixture motion, loss, penetration, bad telemetry, stale observations, acquisition failure and bounded recovery. Numerical success fixtures and ideal tracking are labeled synthetic; neither is a physical or model result.
