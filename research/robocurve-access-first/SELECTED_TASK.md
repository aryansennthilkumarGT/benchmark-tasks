# Selection

**Selected implementation: NONE.** No candidate clears the complete access/source gate. No new mechanism development is justified.

The three fallback screens were selected from the existing 15-task portfolio for accessible external handholds:

1. **Hamilton Beach loaded rotisserie:** broad shaft-end handling, a rigid installation load and two externally inspectable supports. It preserves the documented 1.4 kg load rather than substituting an empty rod. Matching donor/drive/cavity geometry was not identified.
2. **Ninja BL61030 locking lid:** a large original lid/handle and pitcher handhold, with a visible retained-closure endpoint. Matching dimensions and the actual folding-handle/catch linkage remain unsupported.
3. **Opentrons Flex UV lamp:** tool-free insulating-base and elongated-body handling, with a separate remote support and direct robot-equipment relevance. Actual installed-roof size is verified; exact bulb/bay/clip contacts are not.

These choices do not promote published researcher meshes into manufacturer CAD. Hamilton Beach and Ninja fail the source-scale input checks before a valid YAM scene can be justified. Opentrons has only an optimistic installed-roof region survey. No fourth candidate or new discovery bank was opened.
