## Why N040 deserves the first limited prototype

1. **Tighter importance bridge:** O*NET 30.2 mechanics Core 23546 explicitly names power-window lift repair; the read vehicle procedure starts that repair with front-door trim removal. The pinned employment mirror individually exceeds the jobs threshold. This is stronger evidence than borrowing all mechanics for the narrow rear seal in an overhaul chapter.
2. **A concrete physical hypothesis to test cheaply:** an ordinary plastic tool must acquire a real engaged-retainer load path, release it while the panel remains multiply constrained, then permit the actual handle/plug handoff. A small contact unit can falsify this before full-panel construction.
3. **A bounded current comparator:** fresh #1986 is OPEN/awaiting review and its head unchanged; legitimate loose-clip insertion is not automatically the same tool-mediated release/handoff. This is not exhaustive novelty clearance. The prototype must retain the distinguishing release skill; merely reversing a clip push would not suffice.
4. **Less coupled uncertainty than the first alternatives:** N044 adds unmeasured press/impact/lip-observability issues and a weaker specific-duty case. N047 adds two tiny halves, unknown lever/spring load and first-half stability. N022 is independent but introduces two flexible systems and unbound real sleeve/span data.

None of these reasons certifies full-size reach. In particular, the computed0.941269m chain-length sphere is a necessary-only outer bound, and the READY TCP is not an actual service pose. Current full-size door/tool/clip geometry is missing; an impossible full-scale path has neither been proved nor ruled out.
