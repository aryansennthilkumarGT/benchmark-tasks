YUBI Glove Assy_ver.2 Assembly Procedure


【Assembly Procedure】
(1) Install components onto UPPER PLATE
    • Install INSERTs
    • Install BUSHINGs
(2) Install components onto UNDER PLATE
    • Install INSERTs
    • Install BUSHINGs
(3) Install components onto FINGER with Gear_t30_R or t20_R
    • Install RUBBER SHEET
    • Install ENCODER MAGNET
(4) Install components onto FINGER with Gear_t30_L or t20_L
    • Install RUBBER SHEET
(5) Install FINGER with Gear and UPPER PLATE
(6) Install FLAPs                                             【YUBI Glove Assy_ver.2_for Right-hand】
    • Install FLAP_R
    • Install FLAP_L
(7) Install HOLDER_Quest_R/L
    • Install INSERTs
    • Install HOLDER_Quest_R/L
(8) Install PCB and Wiring
    • Install PCB (AS5601) onto UPPER PLATE
    • Install PCB (ESP32C6) on HOLDER_Quest_R/L
    • Install USB TYPE-C CABLE
(9) Install CAMERA
    • Install CAMERA
    • Connect CAMERA WIRING
(10) Install GRIP                                             【YUBI Glove Assy_ver.2_for Left-Hand】
    • Install T-SLOT NUT
    • Install GRIP
    • Adjust GRIP position
(11) Install Rubber Band for Finger opening and closing
(12) Install Meta Quest Touch Plus Controller

(11) Install Rubber Band for Finger Opening and Closing


• Install rubber band No.16 for finger opening and closing as follows.
  ① Hook rubber band No.16 onto the hook at base of the finger.
     Use right-finger side for right-hand version and left-finger side for left-hand Version.
  ② Hook rubber band onto the hook and groove of HOLDER_Quest_R/L.
  ③ Confirm that the fingers open and close smoothly.
